## وصف عربي

تذكيرات بالأذكار أثناء استخدام سطح المكتب، مع جدول أسبوعي وفترات هدوء وإيقاف مؤقت. يمكنك إضافة أذكار مخصصة والتحكم في موضع التنبيه ومدته والشاشة التي يظهر عليها. يدعم التطبيق العربية والإنجليزية، ويحتفظ بالمكتبة والإعدادات وسجل عرض التذكيرات محليًا.

يعمل التذكير دون إنترنت. اختيار فحص التحديثات يفتح صفحة إصدارات المشروع في المتصفح. لا توجد إعلانات أو خدمة تتبع في الكود الحالي.

## English description

Desktop dhikr reminders with a weekly schedule, quiet hours and pause controls. Add custom entries and choose the popup position, duration and display. Arabic and English are supported. Settings, content and delivery history stay on the device.

Reminders work offline. A requested update check opens the project's releases page in your browser. The current source has no advertising or telemetry service.

Suggested search terms: Azkar, Dhikr, Islamic, أذكار، اذكار، تسبيح، استغفار.

Before submission, validate the actual Windows installer/MSIX, screenshots, package identity, privacy link, asset permissions and content references. No memory or antivirus claim is included because no current measurement establishes it.
