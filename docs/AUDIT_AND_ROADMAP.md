# حالة الإصلاحات والمشاكل المتوقعة

الإصدار: 1.2.5 تجريبي. تاريخ التحقق: 15 أكتوبر 2026. نقطة البداية: `8b2084e224f6655b808269ea095703653c5452a1`.

هذه الوثيقة تستبدل خارطة الطريق القديمة التي تضمنت وعودًا غير مثبتة عن الذاكرة وVirusTotal والتوقيع. لا يوجد ضمان لاستهلاك 15 MB أو نتيجة فحص حماية معينة. المشروع يستخدم C++20 وواجهة Qt ثانية إلى جانب Windows الأصلية.

## حدود التحقق

بناء Release نجح على Ubuntu 22.04.5 باستخدام GCC 11.4 وCMake 3.22.1 وQt 6.2.4. نجحت اختبارات النواة 24/24، واختبار الصوت، واختبارات Qt الثمانية، منها إعداد الاختبار وتنظيفه. هذه أعداد حالية وليست وعدًا بأن كل سلوك مغطى.

AppImage اجتازت التشغيل ومنع النسخة الثانية والإغلاق وحفظ المكتبة الفارغة وحماية الملف التالف في VM بدون Qt، ثم على X11 وWayland/Weston headless. بعد إصلاح HarfBuzz اجتازت الحزمة حاوية Ubuntu محدودة لا تحتوي Qt. اختبارات الواجهة تستخدم سطح عرض افتراضيًا.

نجح بناء Windows المحلي، ثم البناء والتشغيل على Windows Server 2025 في GitHub. اجتازت Setup التثبيت وإعادة التثبيت والإزالة مع الاحتفاظ بملف بيانات المستخدم. وُقّعت نسخة MSIX مؤقتة وثُبّتت وفُعّلت عبر AUMID؛ فُحصت هوية العملية وبياناتها الخاصة ثم أُزيلت. نجح بناء واجهتي Windows مع Qt 6.8.3 واختبارات النواة والصوت والواجهة.

بُني تطبيق macOS universal على macOS 14 ARM، واجتاز اختبارات النواة والصوت والواجهة. رُكّبت DMG وشُغّلت حزمة Cocoa الموزعة مع اختبارات Launch Services وIPC وحماية البيانات، ثم شُغّلت شريحة x86_64 عبر Rosetta. هذا لا يعادل جهاز Intel فعليًا. التوقيع Developer ID وnotarization لم يُنفذا. لا يوجد اختبار سماعي على سماعات فعلية. راجع [سجل التحقق](BUILD_VALIDATION.md) للإصدارات والروابط والحدود.

## المشاكل المتبقية وأولوية المتابعة

| الأولوية | الحالة المتوقعة | المطلوب قبل الادعاء بالدعم |
|---|---|---|
| عالية | معاينة macOS تعمل، ومسار Developer ID غير مجرب | Gatekeeper بعد تنزيل الملف، signing/notarization، جهاز Intel فعلي، ثم logout/login وSpaces والصوت |
| عالية | حزم Windows تعمل على runner، لا توجد تجربة مستخدم كاملة على Windows 10/11 | ترقية من إصدار أقدم ببيانات حقيقية، الصوت والتشغيل بعد تسجيل دخول جديد |
| عالية | GNOME قد لا يوفر tray، وWayland يمنع الموضع المطلق | اختبار GNOME/KDE الحقيقيين؛ fallback نافذة رئيسية عند غياب tray وإشعارات نظام للتلقائي |
| متوسطة | Wayland لا يكشف ملء الشاشة العام | الإعداد يُعطّل ويشرح عدم الدعم؛ اختبار سياسة DND على سطح مكتب فعلي |
| متوسطة | صوت Qt يستخدم MP3 الافتراضي/المخصص، وليس كل presets الخاصة بـWindows | توحيد المولدات أو تصميم اختيار أصوات واضح ثم اختبار أجهزة فعلية |
| متوسطة | LaunchAgent على macOS وfullscreen هندسي على الشاشة الرئيسية | تقييم `SMAppService` ودقة عدة شاشات/Spaces في تنفيذ قابل للاختبار |
| متوسطة | قطع الكهرباء أثناء الحفظ | rename يحمي الاستبدال، لكنه ليس ضمان durability لقطع الطاقة؛ لا يوجد fsync للملف والدليل في Unix |
| متوسطة | Qt ليست مطابقة لكل مؤثرات Windows | الأسطح والزخارف وبعض خيارات العداد تحتاج قرار منتج؛ لا يُدّعى التكافؤ الكامل |
| متوسطة | شاشة منفصلة أو DPI/Retina أو تبديل جهاز الصوت | اختبار hotplug والشاشات الفعلية واستعادة الجهاز بعد انقطاعه |
| قبل نشر عام | تراخيص الأصول ومراجع الأذكار | مراجعة مصدر MP3 وصحة مراجع النصوص؛ ملفات تراخيص Cairo/Qt والمكتبات الموردة أضيفت للحزم |
| قبل نشر عام | Microsoft Store/MSIX | التثبيت والتفعيل نجحا بتوقيع اختباري؛ قبول المتجر وترقية MSIX من إصدار سابق لم يُختبرا، وautostart يحتاج مراجعة StartupTask بدل افتراض عمل HKCU Run داخل العزل |

عند تلف مكتبة Qt الحالية، يرجع startup خطأ ويحتفظ بالملف. لاستعادة التشغيل: انسخ `content.json` إلى backup ثم انقله خارج مجلد البيانات وأعد التشغيل لتكوين المكتبة الافتراضية. الإعدادات التالفة تُنسخ إلى ملف `settings-invalid-*.json` قبل حفظ الافتراضيات. لا تحذف النسخة الاحتياطية قبل فحصها.

## قبول الإصدار

لا يُنشر release عام قبل نجاح بناء الأنظمة المستهدفة واختبار artifacts خارج بيئة التطوير. يرفض macOS tag build إنتاج إصدار غير موقّع. ينشئ workflow مسودة prerelease بعد نجاح jobs، ويترك قرار النشر للمطور.
